THE FOG GUIDE — V3 VISUAL
==========================

COMO ABRIR NO VS CODE
1. Extraia este ZIP.
2. Abra a pasta no VS Code.
3. Se aparecer "Restricted Mode", clique e escolha "Trust this folder".
4. Instale a extensão "Live Server".
5. Abra index.html.
6. Botão direito em index.html -> Open with Live Server.

IMPORTANTE
Não abra o index.html como file:/// se estiver usando o Live Server.
O endereço esperado será parecido com:
http://127.0.0.1:5500/index.html

PÁGINAS
- index.html — Home
- comece-aqui.html — primeira partida
- sobrevivente.html — trilha Survivor
- killer.html — trilha Killer
- builds.html — builds por objetivo
- dicionario.html — dicionário pesquisável
- quiz.html — quiz de fundamentos
- style.css — identidade visual
- script.js — interações
